Мини чат на Firestore

Этот сайт заменяет ChatWindow.xaml и работает с той же структурой Firestore: pcList/{pcKey}/chatMessages.

Для GitHub Pages открой сайт так:
?pcKey=PC_...&me=Admin&role=admin
или
?pcKey=PC_...&me=Client&role=client
Важно: это минимальный вариант. Если сайт будет публичным, любой, у кого есть ссылка, сможет открыть чат. Для нормальной защиты потом добавь Firebase Auth и правила безопасности.
