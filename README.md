# 🔥 CYBER CONTROL PANEL

Современная киберпанк админ-панель с крутым дизайном в стиле Matrix/Hacker.

## ✨ Основные возможности

### 🎨 **Визуальный стиль**
- **Matrix зеленый дизайн** - классический хакерский стиль
- **Неоновое свечение** на всех элементах
- **Анимированный фон** с эффектом сканирования
- **Киберпанк градиенты** и эффекты
- **Терминальный шрифт** (Courier New)

### 🎯 **Новое боковое меню**
- **Современная боковая панель** вместо верхнего меню
- **Сворачиваемое меню** - кликните на иконку меню чтобы свернуть/развернуть
- **Сохранение состояния** - запоминает свернутое/развернутое состояние
- **Разделы меню** - Navigation и System
- **Индикаторы статуса** - показывают количество и состояние
- **Кнопка выхода** - красная кнопка отключения внизу

### 📱 **Мобильная версия**
- **Адаптивный дизайн** для всех устройств
- **Плавающая кнопка меню** на мобильных
- **Выдвижное боковое меню** на телефонах
- **Затемнение фона** при открытом меню
- **Touch-friendly** интерфейс

### ⚡ **Улучшения UX**
- **Tooltips** при наведении на кнопки
- **Smooth анимации** переходов
- **Визуальные подсказки** (иконки везде)
- **Улучшенный scrollbar** в киберпанк стиле
- **Быстрый доступ** ко всем функциям

## 🚀 Как использовать

### Десктоп версия:
1. Откройте `index.html` в браузере
2. Войдите или зарегистрируйтесь
3. Используйте боковое меню для навигации
4. Нажмите на иконку меню (☰) чтобы свернуть/развернуть панель

### Мобильная версия:
1. Откройте на телефоне/планшете
2. Нажмите на круглую зеленую кнопку (☰) справа внизу
3. Меню выедет слева
4. Нажмите вне меню чтобы закрыть

## 🎮 Горячие клавиши

- **Сворачивание меню**: Клик по иконке в шапке сайдбара
- **Мобильное меню**: Плавающая кнопка справа внизу

## ⚙️ Особенности реализации

### Боковое меню:
- Сворачивается до 70px (только иконки)
- Анимированное появление badge при сворачивании
- Автосохранение состояния в localStorage
- Плавные CSS transitions

### Анимации:
- Сканирующие линии на панелях
- Пульсирующие badge
- Мерцание индикаторов
- Glitch эффект на заголовках
- Появление элементов при наведении

### Адаптивность:
- Breakpoint на 768px для планшетов
- Breakpoint на 480px для телефонов
- Фиксированное меню на мобильных
- Плавающая кнопка открытия меню
